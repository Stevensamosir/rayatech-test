# Tugas 2 (React + TypeScript)
aplikasi Todo List sederhana berbasis web dengan fitur CRUD dasar: menambah, melihat, mengedit, menandai tugas sebagai selesai, dan menghapus tugas.

Data disimpan `localStorage` browser

## Cara menjalankan
```bash
cd todo-app
npm install
npm run dev
```
(http://localhost:5173).

## Build produksi
```bash
npm run build
npm run preview
```
